# FK-1304 — Authorise a vehicle's return to service Test Plan

## Story

**Key:** `FK-1304`
**Title:** Authorise a vehicle's return to service
**Release:** `2.26`
**Epic:** `FK-1301`

**Acceptance Criteria:**
- **AC1** — Only a transport manager can return a vehicle to service (BR-018).
- **AC2** — A vehicle cannot return to service while any category-A defect on it is not closed (BR-019).
- **AC3** — Once every category-A defect on it is closed, the transport manager can return the vehicle to service; it shows as Roadworthy and the audit trail records it.

## Test case IDs

`FK-1304-TC<NNN>`, three digits, sequential from `001` (I8). Assigned here and nowhere else.

## Scope Notes

Practice-run plan, written by hand in the planner's format. The escalation clock and inspections (BR-020)
are out of scope for this story.

## Module: Vehicles

### FK-1304-TC001 — Validate that a vehicle returns to service once its category-A defect is closed

**Test Type:** Automated
**Story:** FK-1304
**Module:** Vehicles
**Sub Module:** Return to service
**Technique:** State Transition
**Test Steps:**
Given the driver has reported a category-A defect on their vehicle, so it is off the road (`reportDefectPage.report()`)
And the transport manager has triaged it and raised a job card (`defectPage.act()`)
And the technician has started work and marked it resolved (`defectPage.act()`)
And the transport manager has closed it (`defectPage.act()`)
When the transport manager returns the vehicle to service (`vehiclesPage.returnToService()`)
Then the vehicle is shown as Roadworthy (`vehiclesPage.statusOf()`)

**Expected Result:** The Vehicles page shows the message "FK21 ABC is back in service." and the vehicle's Status column reads "Roadworthy".
**Data:** `fleetData.vehicleForReturn`, `fleetData.categoryADescription`, `fleetMessages.backInService`
**Priority:** Priority 1

### FK-1304-TC002 — Validate that return to service is refused while the category-A defect is only resolved

**Test Type:** Automated
**Story:** FK-1304
**Module:** Vehicles
**Sub Module:** Return to service
**Technique:** State Transition
**Test Steps:**
Given the driver has reported a category-A defect on their vehicle, so it is off the road (`reportDefectPage.report()`)
And the defect has been triaged, worked and marked resolved, but not closed (`defectPage.act()`)
When the transport manager tries to return the vehicle to service (`vehiclesPage.returnToService()`)
Then the request is refused (`vehiclesPage.expectMessage()`)

**Expected Result:** The Vehicles page shows "<registration> can't return to service: category-A defect <defect ID> is not closed." and the vehicle's Status column still reads "VOR".
**Data:** `fleetData.secondVehicle`, `fleetData.categoryADescription`, `fleetMessages.returnRefused`
**Priority:** Priority 1

### FK-1304-TC003 — Validate that a driver has no Return to service action on an off-road vehicle

**Test Type:** Automated
**Story:** FK-1304
**Module:** Vehicles
**Sub Module:** Return to service
**Technique:** Decision Table
**Test Steps:**
Given the driver has reported a category-A defect on their vehicle, so it is off the road (`reportDefectPage.report()`)
When the driver opens the Vehicles page (`vehiclesPage.open()`)
Then no Return to service action is offered for that vehicle (`vehiclesPage.returnToServiceButton()`)

**Expected Result:** The vehicle's row shows Status "VOR" and has no "Return to service" button.
**Data:** `fleetData.vehicleForReturn`, `fleetData.categoryADescription`
**Priority:** Priority 2

### FK-1304-TC004 — Validate that the audit trail records a return to service

**Test Type:** Manual
**Story:** FK-1304
**Module:** Vehicles
**Sub Module:** Audit trail
**Technique:** Error Guessing
**Test Steps:**
Given a vehicle has just been returned to service by the transport manager
When the transport manager opens the Audit trail
Then the newest entry records the return to service

**Expected Result:** The Audit trail's newest row shows Theo Manager as Who and "Returned <registration> to service" as What, timestamped within the last minute.
**Data:** `fleetData.vehicleForReturn`
**Priority:** Priority 2
